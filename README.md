# KILLCode

KILLCode 是一个在本机运行的算法学习工具，把学习路线、题目阅读、伪代码练习、个人笔记和 AI 辅导放在同一个工作区。适合按专题持续学习，也可以围绕一道题反复推敲思路、记录问题和复习。

## 主要功能

### 学习路线与进度管理

- 按算法专题分组浏览内容，展开或收起各分类，按题号、标题和内容摘要中的关键词搜索；`Ctrl+K` 可快速定位搜索框。
- 每道题可以标记为“未开始”“学习中”或“已完成”，首页显示完成数量与整体进度。
- “继续学习”入口帮助回到最近打开且尚未完成的题目。
- 收藏需要复习的题目，通过“只看收藏”集中查看。

### 专题训练合集

- **排序 100 题**：分为 8 个模块，按简单、中等、困难组织训练。
- **动态规划 100 题**：分为 10 个模块，覆盖不同动态规划模型与训练重点。
- 合集中的题目显示难度、A/B/C 优先级和训练重点，方便安排学习顺序。
- 支持按合集顺序切换上一题、下一题并返回题单；同一道题在不同入口共享进度、收藏、笔记和 AI 对话。
- 提供考点覆盖说明、22 个专项补题及补充学习材料，便于检查薄弱环节。

### 阅读与独立思考

- 阅读区支持 Markdown、代码高亮、表格和数学公式。
- 记录阅读到的标题位置，再次打开时恢复到相应位置。
- 可开启阅读遮罩，按区域逐步揭示正文，也可以重新遮住已查看的部分，方便先思考再核对。
- 桌面端可同时查看正文与工具面板，调整工具面板宽度和编辑器高度；移动端可切换练习、笔记和 AI 面板。

### 伪代码练习与 AI 评估

- 每道题都有独立的伪代码编辑区，用来整理算法步骤和边界处理，编辑内容自动保存，也支持 `Ctrl+S` 保存。
- 提交后获得结构化思路评估，包括“思路可行”“需要修正”或“信息不足”的结论、主要问题、边界与反例、时间和空间复杂度以及下一步建议。
- 问题反馈可包含对应行号，便于回到编辑器修改。
- 保留多次评估记录及当次代码快照，可以切换查看历史反馈。

评估属于静态思路分析，不会编译、运行代码或执行测试用例。

### 每题独立的 AI 辅导

- 每道题保留独立的对话记录与持续会话，便于围绕同一思路继续追问。
- 提供“给我一个提示”“检查边界条件”“解释复杂度”等快捷提问。
- 支持添加图片、文本和代码文件，也可以粘贴图片辅助描述问题；每次最多添加 4 个附件。
- 可选择本机 Codex 提供的模型与相应思考强度。
- 回答逐步显示，请求失败时保留输入并提供重试入口。
- 有价值的 AI 回答可以一键添加到当前题目的笔记。

### 个人笔记与数据备份

- 每道题提供独立的 Markdown 笔记，支持编辑、预览和自动保存，用来记录解题思路、易错点与复习结论。
- 学习状态、收藏、笔记、伪代码及 AI/评估记录保存在当前浏览器的 IndexedDB 中，关闭页面后仍可继续使用。
- 在“设置与数据”中导出 JSON 备份，或导入备份迁移学习记录。
- 导入前显示题目状态与对话记录数量；按更新时间合并，保留较新的本地记录，并跳过当前内容库中不存在的题目。
- 支持清空当前浏览器的学习记录，以及切换深浅主题和配色。

## 前置条件

- Node.js 20+
- Git，用于克隆项目和初始化子模块
- Codex CLI，且终端中 `codex login status` 显示已通过 ChatGPT 登录

## 从 GitHub 克隆

请连同项目所需的子模块一起克隆：

```powershell
git clone --recurse-submodules https://github.com/yzqnSKY/KILLCode.git
cd KILLCode
```

如果已经普通克隆，请先运行 `git submodule update --init --recursive`，再按下方说明启动。

## 启动

最简单的方式：双击项目根目录的 `一键启动 KILLCode.cmd`。入口会检查运行环境，首次启动时自动安装依赖，自动避开被占用的 3000–3010 端口，服务就绪后再打开浏览器。命令窗口需要保持开启，按 `Ctrl+C` 或关闭窗口即可停止服务；启动失败时窗口会保留错误信息。

也可以手动启动：

```powershell
npm install
npm run content:build
npm run dev
```

访问 `http://127.0.0.1:3000`。若端口占用，Next.js 会显示实际地址。

AI 功能通过本机 Codex CLI 连接服务。可以在“设置与数据”中检查连接和登录状态。登录信息由 Codex CLI 在本机管理，浏览器不会获得 Codex 凭据；提交 AI 请求时，相关题目上下文、输入及附件会发送给 AI 服务。

学习记录只保存在当前浏览器，不会自动跨设备同步。建议定期导出 JSON 备份。

## 内容维护

- 修改合集的分类、顺序和训练重点：编辑 `content/collections/` 下的 JSON 文件。
- 维护专项训练材料与学习说明：编辑 `content/local/` 和 `content/study-guides/` 下的 Markdown 文件。
- 内容修改后运行 `npm run content:build` 重建索引，运行 `npm run content:check` 检查内容。
