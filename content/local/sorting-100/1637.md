# 1637. 两点之间不包含任何点的最宽垂直区域

> 排序合集 · 简单 · C · 八、事件排序、前缀和、离线与分块

## 题意摘要

给出平面点，求内部不含任何点、两侧由点的横坐标界定的最宽垂直区域宽度。

[查看 LeetCode 原题、完整约束及示例](https://leetcode.cn/problems/widest-vertical-area-between-two-points-containing-no-points/)

## 本题训练重点

几何点按 x 排序，相邻差取得最大空隙。
