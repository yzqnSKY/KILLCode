# 920. 播放列表的数量

> 动态规划合集 · 困难 · C · 九、计数、概率与有限记忆自动机

## 题意摘要

生成播放列表使所有歌都出现，重复一首歌前至少播放指定数量其他歌，求方案数。

[查看 LeetCode 原题、完整约束及示例](https://leetcode.cn/problems/number-of-music-playlists/)

## 本题训练重点

已使用歌曲数与重复冷却；推导转移倍数。

## 完成后复盘

- 写清状态含义、目标、转移中每一项与边界。
- 画依赖方向，说明计算顺序；分析状态数与转移成本。
- 最优化题练习恢复一条解；计数题检查重复计数；概率题说明转移权重和概率质量。
