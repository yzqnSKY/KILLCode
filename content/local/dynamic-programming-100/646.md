# 646. 最长数对链

> 动态规划合集 · 中等 · B · 四、单序列、子序列与偏序链

## 题意摘要

若前一数对的第二项小于后一数对的第一项即可连接，求最长链。

[查看 LeetCode 原题、完整约束及示例](https://leetcode.cn/problems/maximum-length-of-pair-chain/)

## 本题训练重点

二次链 DP 与贪心对照；严格连接条件。
