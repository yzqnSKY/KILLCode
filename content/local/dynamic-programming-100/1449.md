# 1449. 数位成本和为目标值的最大数字

> 动态规划合集 · 困难 · C · 三、背包、容量与序列分段

## 题意摘要

每个数位有成本，求总成本恰好为目标的最大整数，不能使用零。

[查看 LeetCode 原题、完整约束及示例](https://leetcode.cn/problems/form-largest-integer-with-digits-that-add-up-to-target/)

## 本题训练重点

成本完全背包先最大化长度，再恢复字典序最优解。

## 完成后复盘

- 写清状态含义、目标、转移中每一项与边界。
- 画依赖方向，说明计算顺序；分析状态数与转移成本。
- 最优化题练习恢复一条解；计数题检查重复计数；概率题说明转移权重和概率质量。
